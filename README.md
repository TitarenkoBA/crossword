# Кроссворды (crossword)

Веб-сайт и PWA-приложение для разгадывания кроссвордов на русском языке.

- **1000 кроссвордов** трёх уровней сложности (350 лёгких, 350 средних, 300 сложных), словарь из ~3000 слов с вопросами и подсказками.
- **Удобно людям, которым трудно пользоваться компьютером**: всё делается одной мышью, крупные кнопки, экранная клавиатура, защита от дрожания рук, высокий контраст, четыре размера текста.
- **Работает в старых браузерах**, вплоть до Chrome 49 на Windows XP, и в современных, включая телефоны.
- **Без сервера, аккаунтов, рекламы и аналитики.** Прогресс хранится в браузере пользователя. После первого посещения сайт работает без интернета.

## Быстрый старт

Нужен Node.js **22.18 или новее** (скрипты генерации написаны на TypeScript и запускаются Node напрямую).

```bash
npm install          # установить зависимости
npm run dev          # режим разработки: http://localhost:5173
npm run build        # собрать сайт в dist/
npm run preview      # посмотреть собранный сайт: http://localhost:4173
```

> В режиме разработки (`npm run dev`) Service Worker не включается, и Vite отдаёт современный код.
> Проверять совместимость со старыми браузерами нужно на собранной версии (`build` + `preview`).

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Сервер разработки с горячей перезагрузкой |
| `npm run build` | Проверка типов и сборка в `dist/` (современный и legacy-бандл, `sw.js`) |
| `npm run preview` | Раздаёт `dist/` локально |
| `npm test` | Все модульные, компонентные и тесты данных (Vitest) |
| `npm run test:watch` | То же в режиме наблюдения |
| `npm run test:coverage` | Тесты с отчётом о покрытии |
| `npm run test:e2e` | Сборка + E2E-тесты в браузере (Playwright) |
| `npm run lint` | ESLint |
| `npm run typecheck` | Проверка типов TypeScript |
| `npm run generate` | Перегенерировать 1000 кроссвордов из словаря |
| `npm run validate-data` | Проверить все кроссворды в `public/data/` |
| `npm run check-compat` | Проверить `dist/` на совместимость с Chrome 49 |
| `npm run icons` | Перерисовать иконки PWA |
| `npm run check` | Всё сразу: типы, линтер, тесты, данные, сборка, совместимость |

Перед коммитом запускайте `npm run check`. Перед выпуском также `npm run test:e2e`.

## Структура

```
crossword/
├─ docs/                  документация (см. ниже)
├─ data-src/dictionary/   словарь: слова, вопросы, подсказки (по темам)
├─ public/data/           готовые кроссворды (генерируются, хранятся в git)
├─ public/                manifest, иконки
├─ build/                 плагины сборки: ES5-legacy, Service Worker
├─ scripts/               генерация, проверка данных и совместимости
├─ src/
│  ├─ core/               логика без React: сетка, игра, генератор, словарь
│  ├─ data/               формат и загрузка кроссвордов
│  ├─ storage/            сохранение в localStorage
│  ├─ state/              настройки, контекст приложения, хук игры
│  ├─ router/             hash-роутер
│  ├─ components/         кнопки, сетка, клавиатура, диалоги…
│  ├─ screens/            экраны: главная, список, кроссворд, настройки, помощь
│  ├─ pwa/                регистрация Service Worker, плашка обновления
│  └─ styles/             темы и базовые стили
└─ tests/e2e/             браузерные тесты (Playwright)
```
