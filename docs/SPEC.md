# Спецификация: crossword

Версия: 0.1 (черновик на согласование)
Дата: 2026-11-07

---

## 1. Что это

**crossword** — веб-сайт и PWA-приложение для разгадывания кроссвордов на русском языке.
Работает полностью в браузере, без сервера и без регистрации: кроссворды поставляются
вместе с приложением как статические файлы, прогресс хранится на устройстве пользователя.

Две главные цели, которые определяют все остальные решения:

1. **Удобство для людей, которым трудно пользоваться компьютером.** Прежде всего для тех,
   у кого есть только мышь (нет клавиатуры или ею тяжело пользоваться), а также для людей
   с тремором, слабым зрением и пожилых пользователей.
2. **Работа в старых браузерах.** Минимальная цель — **Chrome 49** (последняя версия Chrome
   для Windows XP), при этом всё работает и в современных браузерах, включая мобильные.

## 2. Технологии

| Что | Выбор | Почему |
|---|---|---|
| Сборка | Vite (актуальная стабильная) + `@vitejs/plugin-legacy` | Vite собирает два бандла: современный (ES-модули) и legacy (ES5 + SystemJS + полифилы core-js). Chrome 49 не поддерживает ES-модули и автоматически получает legacy-бандл. |
| UI | React **18.3** + TypeScript | React 18 хорошо проверен со старыми браузерами при наличии полифилов. TypeScript упрощает дальнейшую поддержку. |
| Стили | Tailwind CSS **v3.4** + PostCSS + Autoprefixer | Tailwind v4 требует Chrome 111+ (cascade layers, `@property`, `color-mix`), поэтому используется v3. |
| Роутинг | Собственный простой hash-роутер (`#/level/easy`, `#/puzzle/easy-0001`) | Работает на любом статическом хостинге без настройки сервера, минимальный размер. |
| Состояние | React Context + `useReducer` | Без лишних зависимостей. |
| Хранение | `localStorage` (с обёрткой и обработкой ошибок) | Есть в Chrome 49, объёма хватает. |
| Офлайн | Service Worker, написанный вручную на ES5 | Генераторы SW (Workbox) выдают современный JS, который Chrome 49 может не выполнить. Свой SW — около 100 строк, полностью под контролем. |
| Тесты | Vitest + React Testing Library + jsdom; Playwright для e2e | См. раздел 9. |

### 2.1. Ограничения, которые накладывает Chrome 49

Эти правила фиксируются в документации и **проверяются автоматически** (раздел 9.4):

**CSS — запрещено** (нет поддержки в Chrome 49):
- CSS Grid (`display: grid`, Chrome 57+) → используется только flexbox.
- `gap` у flex-контейнеров (Chrome 84+) → отступы через `margin` / `space-x-*`.
- `aspect-ratio`, `inset`, `position: sticky`, `:focus-visible`, `:is()`, `:where()`.
- Цвета вида `rgb(1 2 3 / 50%)` (Chrome 65+). Утилиты прозрачности Tailwind
  (`bg-opacity`, `text-opacity` и т.п.) отключаются в конфиге, чтобы Tailwind генерировал обычные hex-цвета.

**JS — запрещено или только через полифилы:**
- Pointer Events (Chrome 55+) → только `onClick` / `onMouseDown` / touch-события.
- `ResizeObserver`, `IntersectionObserver` → подписка на `window.resize`.
- `async/await`, `Object.entries`, spread и т.п. — допустимы в коде, их транспилирует Babel через plugin-legacy.

**Шрифты:** системные шрифты с кириллицей (Verdana / Tahoma / Arial / system-ui), без загрузки веб-шрифтов.

**Целевой экран минимум:** 1024×768 (типично для ПК на XP) — всё основное должно помещаться без прокрутки.
Также поддерживаются планшеты и телефоны (от 360px ширины).

### 2.2. Известное ограничение XP, не зависящее от кода

Установка PWA «как приложение» в Chrome 49 на Windows XP не поддерживается — там сайт работает
как обычный сайт с офлайн-режимом через Service Worker. Кроме того, на XP могут быть проблемы
с HTTPS-сертификатами современных хостингов (отсутствуют новые корневые сертификаты в системе).
В документации по деплою будет отдельный раздел об этом.

## 3. Доступность: принципы для пользователей «только мышь»

Целевой уровень — WCAG 2.1 AA, плюс дополнительные правила ниже.

### 3.1. Обязательные правила интерфейса
1. **Всё делается одним обычным кликом левой кнопкой.** Нет двойных кликов, правого клика,
   перетаскивания, колеса мыши как единственного способа, долгих нажатий, наведения (hover) как
   единственного способа что-то увидеть.
2. **Крупные цели.** Любая кнопка не меньше 48×48 px (при стандартном масштабе), расстояние между
   соседними кнопками не меньше 8 px. Клетки кроссворда — не меньше 36 px.
3. **Встроенная экранная клавиатура** (ЙЦУКЕН) всегда на экране кроссворда. Вводить буквы можно
   без физической клавиатуры. Плюс кнопки «Стереть», «← Назад», «Вперёд →», «Сменить направление».
4. **Никаких ограничений по времени.** Таймер есть, но скрыт по умолчанию и ни на что не влияет.
5. **Защита от случайных действий.** Сброс кроссворда и «Показать всё решение» — только через
   окно подтверждения с большими кнопками «Да» / «Нет». Любой ввод буквы можно стереть.
6. **Защита от дрожания рук** (настройка, по умолчанию выключена): игнорировать повторное нажатие
   той же кнопки быстрее чем за N мс (300 мс по умолчанию).
7. **Нет мелкой прокрутки.** Длинные списки (вопросы, кроссворды) — с крупными кнопками
   «Выше» / «Ниже» или постраничные, без зависимости от тонкой полосы прокрутки и колеса.
8. **Состояние не только цветом.** Выделенная клетка/слово, ошибка, правильный ответ отличаются
   ещё и толщиной рамки, узором или значком.
9. **Автосохранение** после каждого действия. Закрыл браузер — вернулся туда же.
10. **Простой язык.** Короткие подписи на кнопках, без иконок без текста.

### 3.2. Настройки отображения
- Размер интерфейса: 4 ступени (обычный, крупный, очень крупный, максимальный) — крупными кнопками «А−» / «А+».
- Тема: светлая, тёмная, высокий контраст (чёрно-жёлтая).
- Показывать/скрывать экранную клавиатуру (по умолчанию — показывать).
- Поведение клика по уже выделенной клетке: сменить направление (по умолчанию) или ничего.
- Автопереход к следующему слову после заполнения текущего (по умолчанию — да).
- Защита от дрожания (п. 3.1.6).
- Показ таймера.

### 3.3. Клавиатура и экранные читалки (вторичная поддержка)
- Физическая клавиатура работает полностью: буквы, Backspace, стрелки, Tab (следующее слово), Пробел (сменить направление).
- Видимый фокус на всех элементах, логичный порядок Tab.
- `aria-label` у клеток («3 по горизонтали, буква 2 из 5, пусто»), `aria-live` для текущего вопроса.
- Латинская раскладка автоматически сопоставляется с русскими буквами (q→й и т.д.), чтобы не нужно было переключать язык.
- Буква Ё считается равной Е.

## 4. Экраны

### 4.1. Главная
- Название, три крупных кнопки выбора сложности: **Лёгкие**, **Средние**, **Сложные**
  (с подписью: размер сетки, число слов, сколько решено).
- Кнопка «Продолжить» — если есть незаконченный кроссворд (открывает последний).
- Кнопки «Настройки» и «Как играть».

### 4.2. Список кроссвордов уровня
- Постраничный список: крупные плитки с номерами (например, 20 на страницу).
- У каждой плитки статус: не начат / в процессе (процент) / решён (галочка + текст «Решён»).
- Кнопки «← Предыдущая страница» / «Следующая страница →», номер страницы.
- Кнопка «Случайный нерешённый».

### 4.3. Экран кроссворда (главный экран)
Раскладка на экране ≥1024 px:
```
┌──────────────────────────────────────────────────────────┐
│ ← К списку     Кроссворд №17 (Лёгкий)        Настройки   │
├───────────────────────────┬──────────────────────────────┤
│                           │  ТЕКУЩИЙ ВОПРОС (крупно)     │
│        СЕТКА              │  5 по горизонтали, 6 букв:   │
│                           │  «Столица Франции»           │
│                           │  [Подсказка] [Открыть букву] │
│                           │  [◄ Пред. слово][След. слово►]│
│                           ├──────────────────────────────┤
│                           │  ЭКРАННАЯ КЛАВИАТУРА         │
│                           │  Й Ц У К Е Н Г Ш Щ З Х Ъ     │
│                           │  ...  [Стереть] [Сменить ↔↕] │
├───────────────────────────┴──────────────────────────────┤
│ [Все вопросы] [Проверить слово] [Проверить всё] [Ещё ▾]  │
└──────────────────────────────────────────────────────────┘
```
На узких экранах блоки идут друг под другом: текущий вопрос → сетка → клавиатура.

Взаимодействие:
- Клик по клетке — выделяет её и слово. Повторный клик по той же клетке — смена направления
  (если в клетке пересекаются два слова).
- Клик по вопросу в списке «Все вопросы» — переход к этому слову.
- Ввод буквы — заполняет клетку и переходит к следующей пустой клетке слова.
- Решённые слова в списке вопросов зачёркиваются и помечаются галочкой.
- Когда кроссворд решён — крупное поздравление, итоги (сколько подсказок использовано),
  кнопки «Следующий кроссворд» и «К списку».

**Подсказки** (кнопки, без ограничений, но учитываются в статистике):
1. «Подсказка» — показывает дополнительную текстовую подсказку к слову (у каждого слова в данных есть отдельный текст подсказки).
2. «Открыть букву» — открывает букву в выделенной клетке.
3. «Открыть слово» — открывает текущее слово (в меню «Ещё»).
4. «Проверить слово» / «Проверить всё» — подсвечивает неверные буквы (рамка + значок, не только цвет).
5. «Показать решение» — с подтверждением (в меню «Ещё»).
6. «Начать заново» — с подтверждением (в меню «Ещё»).

Меню «Ещё» — не выпадающее по наведению, а открывающаяся по клику панель с крупными кнопками.

### 4.4. Настройки
Все параметры из п. 3.2. Изменения применяются сразу, есть кнопка «Сбросить настройки».
Отдельная кнопка «Удалить весь прогресс» (с двойным подтверждением).

### 4.5. Как играть
Короткая инструкция крупным текстом с простыми схемами: как выбрать клетку, как вводить буквы
мышью, что делают подсказки.

## 5. Кроссворды и данные

### 5.1. Формат кроссворда
Свободный («журнальный») кроссворд: слова пересекаются, пустые места между ними не заполняются.
Такой формат проще для восприятия и даёт осмысленные пересечения с русским словарём.

| Сложность | Кол-во | Сетка (макс.) | Слов | Длина слов | Словарь и вопросы |
|---|---|---|---|---|---|
| Лёгкий | 350 | 9×9 | 8–10 | 3–7 | частые слова, прямые вопросы («Домашнее животное, мяукает») |
| Средний | 350 | 13×13 | 12–16 | 3–10 | шире словарь, вопросы-описания |
| Сложный | 300 | 15×15 | 18–24 | 4–13 | редкие слова, термины, вопросы с подвохом |
| **Итого** | **1000** | | | | |

### 5.2. Источник данных
Всё генерируется в рамках проекта (без сторонних словарей и API):

1. **Словарь** (`data-src/dictionary/*.json`) — составляется вручную (мной) по тематическим
   файлам: природа, животные, география, быт, еда, профессии, искусство, наука, история, спорт и т.д.
   Цель — **~3000 слов**. У каждого слова:
   - `word` — ответ (заглавные, без Ё);
   - `clues` — вопрос(ы) по уровням сложности (`easy` / `medium` / `hard`, минимум один);
   - `hint` — дополнительная подсказка (другая формулировка, подсказка-ассоциация);
   - `level` — минимальная сложность, на которой слово допустимо;
   - `topic` — тема.
2. **Генератор** (`scripts/generate.ts`, запускается `npm run generate`) — детерминированный
   (фиксированный seed): строит сетки из словаря, равномерно распределяет слова (чтобы одно слово
   не повторялось слишком часто), исключает дубли кроссвордов.
3. **Результат** (`public/data/`) — коммитится в репозиторий, чтобы сборка не зависела от генерации:
   - `index.json` — список кроссвордов по уровням (id, размер, кол-во слов);
   - `easy/chunk-00.json` … — пачки по 50 кроссвордов (загружаются по требованию, ~100 КБ каждая).

Добавить свои слова или перегенерировать набор можно по инструкции в `docs/DATA.md`.

### 5.3. Валидация данных
Отдельный скрипт и тесты проверяют каждый из 1000 кроссвордов: пересечения совпадают по буквам,
слова не слипаются с соседями, у каждого слова есть вопрос и подсказка, id уникальны, нет повторов
слов внутри кроссворда, кроссворд связный (все слова соединены).

### 5.4. Прогресс (localStorage)
```
crossword:v1:settings        — настройки
crossword:v1:progress:<id>   — введённые буквы, открытые подсказки, статус, время
crossword:v1:last            — id последнего открытого кроссворда
```
Версия ключа (`v1`) позволяет мигрировать данные в будущем. При недоступном localStorage
(режим инкогнито, переполнение) приложение продолжает работать без сохранения и показывает
понятное предупреждение.

## 6. PWA и офлайн
- `manifest.webmanifest`: название, иконки 192/512 (+ maskable), `display: standalone`, цвет темы.
- Service Worker (ES5, вручную):
  - при установке кэширует оболочку приложения (HTML, JS, CSS, иконки, `index.json`);
  - пачки кроссвордов кэшируются при первом открытии (cache-first);
  - на главной — кнопка «Скачать все кроссворды для работы без интернета» (~2 МБ);
  - при выходе новой версии — плашка «Доступно обновление» с кнопкой «Обновить».
- В браузерах без Service Worker сайт просто работает онлайн.

## 9. Тестирование

### 9.1. Модульные (Vitest)
- `core`: построение модели сетки, навигация (следующая клетка, смена направления, переходы между словами),
  ввод, проверка, подсказки, определение решённости, нормализация букв (Ё→Е, латиница→кириллица).
- Генератор: детерминированность, корректность пересечений, соблюдение лимитов сложности.
- `storage`: сохранение/загрузка, недоступный localStorage, миграции.
- Роутер, редьюсеры.
- Порог покрытия для `src/core` — не ниже 90%.

### 9.2. Компонентные (React Testing Library)
- Экранная клавиатура вводит буквы, «Стереть» работает.
- Клик по клетке / по вопросу выделяет слово; повторный клик меняет направление.
- Диалоги подтверждения; защита от дрожания; настройки применяются.

### 9.3. Данные
- Тест проходит по всем 1000 кроссвордам и проверяет правила из п. 5.3.

### 9.4. Совместимость (автоматически, в `npm run check`)
- `es-check es5` на legacy-бандле — нет синтаксиса новее ES5.
- Проверка собранного CSS на запрещённые свойства (grid, gap, aspect-ratio, `rgb(... / ...)` и т.д.).
- Проверка, что `sw.js` — ES5.

### 9.5. E2E (Playwright, Chromium)
- Полное решение кроссворда **только мышью** (без единого нажатия клавиши).
- Решение с физической клавиатуры.
- Сохранение прогресса после перезагрузки.
- Работа офлайн после первого посещения.
- Проверка размеров кликабельных элементов (≥48 px) на ключевых экранах.

### 9.6. Ручная проверка
Чек-лист в `docs/COMPATIBILITY.md` для прогона в виртуальной машине с Windows XP + Chrome 49
(автоматизировать запуск Chrome 49 не получится, но проверки из 9.4 закрывают основные риски).

## 10. Этапы и коммиты
Работа идёт по этапам, каждый — отдельный коммит (или несколько). **Ничего не пушится.**

1. Спецификация (`docs/SPEC.md`), `git init`, `.gitignore`.
2. Каркас: Vite + React + TS + Tailwind 3 + plugin-legacy, ESLint/Prettier, Vitest, базовые скрипты.
3. Проверки совместимости (es-check, проверка CSS) — сразу, чтобы ловить проблемы с самого начала.
4. `src/core`: модель кроссворда, навигация, ввод, проверка + тесты.
5. Генератор и валидатор + тесты.
6. Словарь (несколькими коммитами по темам).
7. Генерация 1000 кроссвордов + тест данных.
8. Хранилище, состояние, роутер + тесты.
9. UI-компоненты: кнопки, диалоги, клавиатура, сетка, список вопросов + тесты.
10. Экраны: главная, список, кроссворд, настройки, помощь.
11. PWA: manifest, иконки, Service Worker, офлайн, обновление.
12. E2E-тесты.
13. Документация.
14. Финальная проверка: сборка, все тесты, проверка совместимости.

## 11. Что не входит в первую версию
- Аккаунты, сервер, синхронизация между устройствами.
- Рейтинги, соревнования, реклама.
- Печать кроссвордов, другие языки, другие типы кроссвордов (сканворды, японские).

## 12. Согласованные решения
1. **Язык** — кроссворды и интерфейс на русском.
2. **Формат** — свободный кроссворд (п. 5.1).
3. **Распределение** — 350 / 350 / 300.
4. **Хостинг** — GitHub Pages. Сборка использует относительный базовый путь (`base: './'`),
   поэтому сайт работает из любой подпапки (`https://<user>.github.io/crossword/`) без настройки.
5. **Некоммерческий проект**: без сервера, без аккаунтов, без рейтингов, без рекламы,
   без аналитики и сторонних запросов. Всё работает статически.
