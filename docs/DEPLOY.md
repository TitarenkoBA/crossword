# Публикация

Сайт полностью статический: после `npm run build` достаточно выложить папку `dist/` на любой
хостинг. Пути относительные (`base: './'`), роутинг через `#`, поэтому сайт работает из любой подпапки
без настройки сервера.

## GitHub Pages (рекомендуется)

В репозитории есть workflow `.github/workflows/deploy.yml`. При каждом пуше в ветку `main` он:
1. ставит зависимости;
2. запускает проверки (типы, линтер, тесты, данные);
3. собирает сайт и проверяет совместимость;
4. публикует `dist/` на GitHub Pages.

Первая настройка:

1. Создайте репозиторий на GitHub, например `crossword`, и отправьте туда код:
   ```bash
   git remote add origin https://github.com/<user>/crossword.git
   git push -u origin main
   ```
2. На GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Дождитесь зелёной галочки во вкладке **Actions**. Сайт будет по адресу
   `https://<user>.github.io/crossword/`.

Если не хотите публиковать на каждый пуш, замените в `deploy.yml` блок `on: push`
на `on: workflow_dispatch`. Тогда запуск будет вручную, кнопкой во вкладке Actions.

### Вручную, без Actions

```bash
npm run check                      # всё проверить и собрать
npx gh-pages -d dist               # выложить dist/ в ветку gh-pages
```
и в **Settings → Pages** выберите источник «Deploy from a branch → gh-pages».

## Другой хостинг

Любой статический хостинг: Netlify, Cloudflare Pages, свой nginx. Выкладывается содержимое `dist/`.
Рекомендации для своего сервера:
- обязательно HTTPS, иначе не заработает офлайн-режим;
- `sw.js` и `index.html` отдавать с `Cache-Control: no-cache`, чтобы обновления приходили сразу;
- `assets/*` можно кешировать надолго (в именах файлов есть хеш);
- включить gzip/brotli для `.json`: данные кроссвордов сжимаются примерно в 5 раз.

## Выпуск новой версии

1. `npm run check` и `npm run test:e2e`.
2. Увеличьте `version` в `package.json` (для истории; на работу сайта не влияет).
3. Коммит и пуш.

У пользователей, которые уже открывали сайт, появится плашка «Доступна новая версия сайта» с кнопкой
«Обновить». Прогресс при обновлении сохраняется. Если вы перегенерировали кроссворды, прочитайте
предупреждение в [DATA.md](DATA.md).

## Несколько PWA на одном github.io

Все репозитории пользователя публикуются на одном домене `https://<user>.github.io/`, и для браузера
это один сайт. Если манифест другого проекта не ограничивает область действия своей папкой
(например, `"start_url": "/index.html"` без `scope` — тогда областью становится весь домен `/`),
установленное приложение «накрывает» и `/crossword/`, а Chrome на Android сообщает, что
«Кроссворды» уже установлены.

Решение — в манифестах **всех** проектов на этом домене указывать относительные адреса:
```json
"id": "./",
"start_url": "./",
"scope": "./"
```
После исправления чужого манифеста удалите то приложение с телефона и установите заново:
Android обновляет область уже установленного приложения не сразу.
