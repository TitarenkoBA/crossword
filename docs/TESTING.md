# Тесты

```bash
npm test               # всё, кроме браузерных (≈20 секунд)
npm run test:watch     # режим наблюдения при разработке
npm run test:coverage  # с отчётом о покрытии (coverage/index.html)
npm run test:e2e       # сборка + тесты в браузере (≈1 минута)
npm run check          # типы, линтер, тесты, данные, сборка, совместимость
```

Перед первым запуском E2E установите браузер: `npx playwright install chromium`.

| Вид | Где | Что проверяет |

| Логика игры | `src/core/*.test.ts` | Сетка, ввод, стирание, переходы, подсказки, проверка, решение, сохранение прогресса, клавиши (в т. ч. Chrome 49 без `key`), буквы и раскладки |
| Генератор и словарь | `src/core/generator.test.ts`, `dictionary.test.ts` | Детерминированность, корректность сеток, ошибки словаря |
| Хранилище, настройки, роутер, загрузчик | `src/storage`, `src/state`, `src/router`, `src/data` | Поломки localStorage, битые данные, ошибки сети, кеширование |
| Компоненты | `src/components/components.test.tsx` | Кнопки и защита от дрожания, клавиатура, сетка, диалоги, списки |
| Экраны | `src/App.test.tsx` | Пути пользователя мышью: главная → список → кроссворд → поздравление; настройки; ошибки загрузки |
| PWA | `src/pwa/register.test.tsx`, `build/service-worker.test.ts` | Регистрация SW, обновление; сам SW (выполняется в имитации воркера) |

Порог покрытия для `src/core` — 90% (настроен в `vitest.config.ts`, `npm run test:coverage` упадёт при снижении).

## Как писать тесты

- **Новая игровая логика** — сначала тест в `src/core/game.test.ts`. Маленький кроссворд для тестов
  лежит в `src/test/fixtures.ts` (КОТ / ТОК / КИТ, схема в комментарии).
- **Компоненты** — `renderWithApp(<Компонент />, { settings, store, now })` из `src/test/render.tsx`:
  он оборачивает компонент в `AppProvider` с хранилищем в памяти и фальшивым загрузчиком кроссвордов.
- **Экраны** — `src/App.test.tsx`: рендер `<App store loader />`, переход через `window.location.hash`.
- Находите элементы так, как их видит человек: `getByRole('button', { name: 'Стереть' })`.
  Если элемент не находится по роли и подписи, скорее всего, есть проблема доступности.
- Тексты тестов пишем по-русски, как и остальной проект.

## E2E

`playwright.config.ts` запускает `vite preview` на порту 4173 (или использует уже запущенный).
Окно 1024×768, как у типичного компьютера с XP. Тест «только мышью» подменяет `page.keyboard`,
так что любое нажатие клавиши уронит тест.
