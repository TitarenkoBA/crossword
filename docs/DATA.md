# Данные: словарь и кроссворды

```
data-src/dictionary/*.txt  ──npm run generate──▶  public/data/index.json
       (вы правите)                                public/data/<уровень>/chunk-NN.json
                                                   (генерируется, хранится в git)
```

## Словарь

Файлы `data-src/dictionary/<тема>.txt`, одна строка — одно слово, поля через `|`:

```
# Комментарий
# СЛОВО | уровень | вопрос | подсказка
КОТ | 1 | Домашний любимец, ловит мышей | Мяукает и мурлычет
```

| Поле | Правила |
|---|---|
| Слово | Только русские буквы, от 3 до 15. Регистр и Ё не важны: всё приводится к заглавным, Ё становится Е. Без пробелов и дефисов. |
| Уровень | `1` — простое слово (лёгкие кроссворды), `2` — среднее, `3` — редкое или термин. |
| Вопрос | Показывается в кроссворде. Не должен содержать сам ответ или однокоренное слово, начинающееся с ответа (`лесной` для ЛЕС). |
| Подсказка | Показывается по кнопке «Подсказка»: другая формулировка, ассоциация, цитата. Тоже не должна содержать ответ. |

Каждое слово может встречаться только в одном файле, иначе у него получилось бы два вопроса.

Сейчас в словаре около 3000 слов в 18 темах.

### Как добавить или исправить слова

1. Отредактируйте нужный `.txt`, или создайте новый файл темы: имя файла считается названием темы.
2. `npm run generate`. Скрипт проверит словарь и, если есть ошибки, покажет файл и номер строки.
3. `npm test`: тест данных убедится, что `public/data` совпадает с результатом генератора.
4. Закоммитьте и словарь, и `public/data`.

> **Важно:** после перегенерации кроссворды с теми же номерами могут стать другими,
> и прогресс пользователей по ним сбросится (несовпадающие сохранения игнорируются).
> Если сайт уже опубликован, лучше накапливать правки словаря и перегенерировать редко.
> Исправление опечатки в вопросе или подсказке номера не меняет, только текст.

### Типичные ошибки генерации

| Сообщение | Что делать |
|---|---|
| `…: ожидается 4 поля через «|»` | В строке не хватает поля или лишний символ `|` |
| `…: слово должно состоять только из русских букв` | Уберите пробел, дефис, латинскую букву |
| `…: вопрос или подсказка … содержит само слово` | Переформулируйте |
| `Слово «X» повторяется: темы «a» и «b»` | Удалите одну из строк |
| `Не удалось сгенерировать N кроссвордов уровня …` | Мало подходящих слов: добавьте слов нужного уровня и длины |

## Генератор

`src/core/generator.ts`. Кроссворд свободной формы:
1. Первое длинное слово кладётся по горизонтали в середину поля.
2. На каждом шаге берётся случайная выборка слов, и для каждого ищется место поперёк уже стоящих слов через общую букву.
3. Выбирается вариант с наибольшим числом пересечений, реже использованным словом и подходящим уровнем.
4. Сетка обрезается по рамке, слова нумеруются в порядке чтения.

Правила (их проверяет `src/core/validate.ts` для каждого кроссворда):
- слова не «слипаются»: любая непрерывная полоска из 2+ букв — это слово кроссворда;
- все слова связаны пересечениями;
- нет повторов слов внутри кроссворда и одинаковых наборов слов между кроссвордами;
- нумерация 1, 2, 3… в порядке чтения, у сетки нет пустых краёв;
- размер сетки, число слов и длина слов — в пределах уровня.

Генерация **детерминированная**: при неизменном словаре получается тот же набор. Это проверяет
`scripts/dataset.test.ts`. Чтобы получить совсем другие кроссворды из того же словаря, поменяйте
`SEED_PREFIX` в `scripts/dataset.ts`.

### Настройки уровней

`LEVELS` в `src/core/generator.ts`:

| | Кол-во | Макс. сетка | Слов | Длина | Уровни слов (вес) |
|---|---|---|---|---|---|
| easy | 350 | 9×9 | 8–10 | 3–7 | 1 |
| medium | 350 | 13×13 | 12–16 | 3–10 | 1 (×1), 2 (×3) |
| hard | 300 | 15×15 | 18–24 | 4–13 | 2 (×1), 3 (×3) |

Если меняете количество, обновите и ожидания в `scripts/dataset.test.ts`. Подписи уровней
для интерфейса лежат в `src/screens/levels.ts`.

## Формат файлов в public/data

`index.json`:
```json
{
  "version": "8c3bd775a661",
  "chunkSize": 50,
  "levels": { "easy": { "count": 350, "chunks": 7 }, "medium": {…}, "hard": {…} }
}
```

`easy/chunk-00.json`: кроссворды 1–50 уровня, по одному на строку (чтобы `git diff` был читаемым):
```json
{"level":"easy","chunk":0,"puzzles":[
{"id":"easy-0001","index":1,"difficulty":"easy","width":8,"height":8,"words":[
  {"number":1,"direction":"across","row":0,"col":0,"answer":"НИЗ","clue":"…","hint":"…"}, …]},
…
]}
```

- `version` — хеш содержимого. Загрузчик добавляет его к адресам пачек (`?v=…`), чтобы браузер не взял устаревшую пачку из кеша.
- Координаты `row`/`col` отсчитываются от нуля, от левого верхнего угла.
- Весь набор весит около 2,2 МБ (в сжатом виде при передаче примерно в 5 раз меньше).

## Проверка

- `npm run validate-data` — все правила для всех 1000 кроссвордов, соответствие словарю и оглавлению.
- `npm test` — то же плюс сравнение с генератором.
