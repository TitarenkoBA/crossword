# Доступность

Главные пользователи — люди, которым трудно пользоваться компьютером: только мышь (без клавиатуры),
тремор, слабое зрение, пожилой возраст. Цель — WCAG 2.1 AA и правила ниже.
**Любое изменение интерфейса проверяйте по этому чек-листу.**

## Оформление и специальные возможности

Обычное оформление — современное и спокойное (светлая или тёмная тема, системный шрифт).
Зрительные специальные возможности **по умолчанию выключены** и включаются в «Настройках» одним
переключателем «Специальные возможности для зрения». После включения доступны размер текста
(4 ступени) и высокий контраст; шрифт меняется на более разборчивый Verdana. Пока переключатель
выключен, выбранные значения запоминаются, но не применяются.

Все остальные правила ниже (крупные кнопки, только клики, защита от случайных действий) действуют
всегда, независимо от переключателя.

## Чек-лист

### Управление
- [ ] Всё делается **одним обычным кликом левой кнопкой**. Нет двойного клика, правого клика, перетаскивания, долгого нажатия.
- [ ] Ничего не появляется только при наведении (hover). Наведение может лишь подсвечивать.
- [ ] Колесо мыши не единственный способ: у прокручиваемых списков есть кнопки «▲ Выше» / «▼ Ниже» (`ScrollBox`), длинные списки разбиты на страницы.
- [ ] Ввод букв возможен с экранной клавиатуры (`ScreenKeyboard`).
- [ ] Новые кнопки сделаны через компонент `Button`: он даёт нужный размер и защиту от дрожания (`guard`). Если пишете свой `<button>`, оборачивайте обработчик в `guard(key, fn)` из `useApp()`.
- [ ] Опасные действия (сброс, показ решения, удаление прогресса) требуют подтверждения через `ConfirmDialog`. В диалоге фокус стоит на безопасной кнопке.
- [ ] Нет ограничений по времени. Таймер скрыт по умолчанию и ни на что не влияет.
- [ ] Всё сохраняется автоматически, кнопки «Сохранить» нет.

### Размеры
- [ ] Кнопки не меньше **3rem × 3rem**: 48 px при обычном размере текста (по умолчанию), больше — при крупном. Классы `min-h-target` / `min-w-target`.
- [ ] Между соседними кнопками есть зазор (обёртки `p-1`/`p-2`).
- [ ] Размеры в `rem`, чтобы настройка «Размер текста» увеличивала всё сразу.

### Зрение
- [ ] Контраст основного текста не ниже 7:1, крупного — не ниже 4.5:1. Цвета берутся только из переменных темы (`src/styles/index.css`).
- [ ] Состояние передаётся не только цветом: выбранная клетка — толстая рамка, ошибка — зачёркивание и значок «×», решённое слово — «√ готово».
- [ ] Новый интерфейс проверен в светлой и тёмной теме и с включёнными спецвозможностями (крупный текст, высокий контраст). В контрастной теме тени отключены, рамки толстые — используйте классы `card`, `btn`, `kb-key`, чтобы это работало автоматически.
- [ ] Используются только символы, которые есть в шрифтах Windows XP (см. [COMPATIBILITY.md](COMPATIBILITY.md)). Эмодзи не используются.
- [ ] Подписи — короткими понятными словами, у каждой кнопки есть текст (не только значок).

### Клавиатура и экранные читалки (вторичная поддержка)
- [ ] Видимый фокус (`:focus`, не `:focus-visible`), логичный порядок Tab.
- [ ] У клеток есть `aria-label` («Клетка: 3 по горизонтали. Буква К»), текущий вопрос объявляется через `aria-live`.
- [ ] Диалоги: `role="dialog"`, `aria-modal`, закрываются по Escape.

| Защита от дрожания: повтор той же кнопки быстрее 0,2–0,8 с игнорируется | `state/AppContext.tsx` → `guard` |
| Светлая и тёмная тема; спецвозможности для зрения (4 размера текста, высокий контраст, шрифт Verdana) — выключены по умолчанию, включаются одним переключателем | `state/settings.ts` (`visualAids`, `effectiveScale`, `effectiveTheme`), `styles/index.css` |

## Размер клеток сетки

Клетки подстраиваются под свободное место. Окно 1024×768:

| Размер текста | Раскладка | Лёгкий | Средний | Сложный |
|---|---|---|---|---|
| Обычный (по умолчанию) | сетка + панель рядом | 61 px | 37 px | 32 px |
| Крупный | сетка + панель рядом | 52 px | 32 px | 28 px |
| Очень крупный, Максимальный | всё друг под другом, страница прокручивается | 72 px | 56 px | 49 px |

В широкой раскладке на 1024×768 сложные кроссворды (15×15) получают маленькие клетки: ограничивает
высота экрана. Компромисс сознательный, потому что весь кроссворд виден без прокрутки. Пользователю,
которому трудно попадать в клетки, есть два пути:
- выбрать слово кликом по большой кнопке («След. слово ►», список «Все вопросы»), а буквы вводить
  экранной клавиатурой: по клеткам кликать не обязательно;
- включить «Специальные возможности для зрения» и размер «Очень крупный»: интерфейс перейдёт в вертикальную раскладку с клетками около 50 px.

Это объяснено на экране «Как играть».

## Как проверять

- Автоматически: `npm run test:e2e`. Тесты решают кроссворд только мышью (клавиатура в тесте запрещена),
  проверяют размер кнопок (не меньше 48×48), отсутствие горизонтальной прокрутки и то, что на 1024×768
  экран кроссворда помещается целиком.
- Вручную: пройдите сценарий только мышью, при «Максимальном» размере текста и в теме «Высокий контраст».
